# web-development

## Workflow and rules

Inspect existing stack; prefer Django templates, Tailwind and HTMX for simple server-rendered projects, not mandatory for every project. Use semantic HTML, progressive enhancement, reusable components and server-side validation. Escape template values in JavaScript with escapejs or json_script; never inject untrusted HTML. Keep secrets server-side. Build assets, run tests and inspect mobile/desktop behavior. Avoid adding dependencies without a clear need.

## Completion

Report what changed, checks actually performed, failures and unresolved risks. Do not claim success without evidence.
