# seo-accessibility

## Workflow and rules

Use semantic landmarks, meaningful titles, metadata, canonical URLs and sitemap for public pages only. Prevent indexing private areas; robots.txt is not access control. Verify keyboard navigation, contrast, focus, labels, headings, error announcements, reduced motion and RTL. Target WCAG 2.2 AA where applicable; use automated checks plus manual review.

## Completion

Report what changed, checks actually performed, failures and unresolved risks. Do not claim success without evidence.
