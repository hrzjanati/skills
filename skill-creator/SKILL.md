# skill-creator

## Workflow and rules

Use a directory matching lowercase hyphenated name and SKILL.md YAML frontmatter with name and description. Write actionable triggers, workflow, guardrails and verification. Keep main instructions concise and put detailed material in references/; include scripts only when necessary. Check dependencies, licenses and source provenance. Test with realistic prompts and negative cases; do not claim validation without running it. Reference https://agentskills.io/specification and https://github.com/anthropics/skills/tree/main/skills/skill-creator .

## Completion

Report what changed, checks actually performed, failures and unresolved risks. Do not claim success without evidence.
