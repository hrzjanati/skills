# python-development

## Workflow and rules

Inspect existing Python version and dependency manager; use pyproject.toml/uv or existing requirements convention. Prefer small typed functions, explicit exceptions, context managers and structured logging. Avoid broad exception swallowing, mutable defaults and hidden I/O. Use Ruff and a type checker where compatible. Pin dependencies and run targeted tests. Reference https://github.com/trailofbits/skills for modern Python practices.

## Completion

Report what changed, checks actually performed, failures and unresolved risks. Do not claim success without evidence.
