# webapp-testing

## Workflow and rules

Use Playwright and stable role/label locators. Verify primary journeys, validation, loading, errors, mobile/desktop, RTL and keyboard interaction. Use seeded synthetic accounts, mock paid services and prohibit production writes. Capture screenshots/traces on failure, redact personal data. Run browser tests against a known build; distinguish visual review from passing assertions. Reference https://github.com/anthropics/skills/tree/main/skills/webapp-testing .

## Completion

Report what changed, checks actually performed, failures and unresolved risks. Do not claim success without evidence.
