# monitoring-logging

## Workflow and rules

Use structured logs and redact personal data, tokens and request bodies. Separate environments, disable production telemetry in tests, and handle optional monitoring initialization failures without crashing. Monitor latency, errors, queue depth and worker freshness. For long-running Django commands refresh stale DB connections before iterations. Set actionable alerts and verify health endpoints without leaking internals.

## Completion

Report what changed, checks actually performed, failures and unresolved risks. Do not claim success without evidence.
