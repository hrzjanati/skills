# performance-optimization

## Workflow and rules

Establish baseline latency, query count, memory and bundle size. Profile before changing code. Eliminate N+1 queries, paginate large lists, index measured query patterns and cache only with correct authorization/invalidation. Optimize images and assets. Choose background work appropriate to actual resource budget; do not assume a fixed server limit. Compare before/after metrics and rerun correctness tests.

## Completion

Report what changed, checks actually performed, failures and unresolved risks. Do not claim success without evidence.
